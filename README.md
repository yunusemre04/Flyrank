# FlyRank Backend Internship

This repository contains my work completed during the **FlyRank Backend Internship**.

Throughout the internship, I will build a collection of backend projects while learning modern backend development concepts such as REST APIs, HTTP, databases, authentication, testing, deployment, and more.

Each week's assignment is organised in its own folder with a dedicated README containing project-specific documentation.

## How to Navigate

Each weekly folder contains:

- Source code
- Individual project README
- Installation instructions
- Usage examples
- Assignment-specific documentation

Please refer to the README inside each week's folder for detailed information.
